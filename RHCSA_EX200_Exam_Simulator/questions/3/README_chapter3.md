# Chapter 03 – Create simple shell scripts

This chapter adds 30 RHCSA-style scripting labs. The questions are intentionally independent and use `/root/scripts`, `/root/reports`, and `/tmp/exam` as predictable exam-style paths.

Focus areas:

- executable Bash scripts
- positional parameters
- variables
- if/then/else
- case statements
- for loops
- while read loops
- CSV parsing
- grep/awk/sed/find
- logging and stderr
- cron integration
- idempotent scripts
- audit/report scripts

Containers/Podman are deliberately not part of this chapter. Flatpak remains part of Chapter 02 / future Chapter 08 software management.
